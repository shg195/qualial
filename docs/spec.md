## 概要
- 名称：**クオリアル ─ Qualial**
- タグライン：「緑」と「青」の境目を測る
- 言語：日本語（`<html lang="ja">`）
- 構成：単一HTMLファイル（CSS/JS インライン）

## 診断ロジック
- 出題数：**8 問**（`TOTAL_QUESTIONS = 8`）
- 色相範囲：`HUE_MIN = 155` 〜 `HUE_MAX = 210`（HSL）
- 彩度・明度：`SATURATION = 78`, `LIGHTNESS = 50`（固定）
- 出題色決定：現在の探索範囲 `[lowBound, highBound]` の中点付近にランダムジッター（±最大 4°）を加える
- 投票：
  - 「青」と判断 → `highBound = currentHue` に更新（青側を狭める）
  - 「緑」と判断 → `lowBound = currentHue` に更新（緑側を狭める）
- 最終結果：`finalHue = round((lowBound + highBound) / 2)`
- これが「あなたの『緑』と『青』の境目」として表示される

## 操作仕様
### カード操作（テスト画面）
- **ドラッグ**：カードを左右にドラッグ
  - コミット閾値：`COMMIT_THRESHOLD = 130 px`
  - 閾値未満で離す：中央へスナップバック
  - 閾値以上で離す：その方向に投票
  - 閾値超過分はラバーバンド減衰（`RUBBER_DAMP = 0.28`、最大超過 50px）
  - 傾き：`TILT_FACTOR = 0.18`、最大 ±24°
- **基準色クリック**：左の緑または右の青ブロックをクリックでも投票できる（補助）
- **キーボード**：
  - `←` / `g` / `G` → 緑投票
  - `→` / `b` / `B` → 青投票
- 投票時：カードが該当方向へ飛ぶアニメーション（450ms）後、次の問題のカードが下から登場

### イントロ画面のデモアニメーション
- ループ動作：左飛び → 右飛び の繰り返し
- 各サイクルでランダム色を表示
- 「は じ め る」を押すと停止

### ヘルプモーダル
- LP / テスト画面の `?` アイコンから開く
- 内容：
  1. 「はじめる」を押すと診断が開始（全 8 問）
  2. 緑と感じたら左、青と感じたら右へドラッグ
  3. 終了後、境目となる色が表示される
- 閉じる：背景クリック／× ボタン／Escape キー

### リセット
- テスト画面のリセットボタン → イントロ画面に戻る（探索範囲・進捗もリセット）

### 結果画面
- 境界色スウォッチ：`hsl(finalHue, 78%, 50%)` の正方形
- 色相表示：`finalHue` を整数で表示（°付き）
- グラデーションバー：`HUE_MIN` から `HUE_MAX` までの色相グラデ
- マーカー位置：`((finalHue - HUE_MIN) / (HUE_MAX - HUE_MIN)) * 100 %`
- 中間色サンプル：オフセット `[-15, -7, 0, 7, 15]` を `finalHue` に加算した5色（範囲を超えるものはクランプ）
- コピー機能：`navigator.clipboard.writeText` で結果テキストをコピー
  - フォーマット：
    ```
    色相 {hue}°
    この色が、私の「緑」と「青」の境目です。

    私はこの色をこう感じます。
    中間色を、緑 {greenCount} 色 / 青 {blueCount} 色 と感じました。
    ```
  - コピー成功時：ボタンラベルが「コ ピ ー し ま し た」に 1.8 秒間変わる
- 「も う 一 度」：そのまま新規テストを開始

### 結果画面のアクションボタン（M2 で追加）
- ボタン構成：4つ（左から「もう一度」「結果をコピー」「画像を保存」「Xで共有」）
- **「画像を保存」**：結果カードを Canvas で動的生成し PNG としてダウンロード
  - 画像サイズ：**810×1080 px**（縦長 3:4）
  - ファイル名：`kuoriaru-{hue}.png`
  - 画像内に含める要素：
    - ブランド名「クオリアル」と「─ Qualial ─」
    - 「私 の 境 目」見出し
    - 境界色スウォッチ（hsl(finalHue, 78%, 50%) の正方形）
    - 色相数値「{hue}°」と「色相」キャプション
    - 中間色サンプル 5 色（finalHue + SAMPLE_OFFSETS でクランプ）
    - 「緑 ← 境目 → 青」軸ラベル
    - サイトURL（小さく下部）
  - 文言は「**境目**」で統一（description 以外はサイト本文と整合）
  - フォントは Google Fonts ロード完了を待つ（`document.fonts.ready` を await）
- **「Xで共有」**：`https://twitter.com/intent/tweet?...` を新規タブで開く
  - text：`色相 {hue}° ─ 私の「緑」と「青」の境目です。\nクオリアル ─ Qualial で診断`
  - url：`SITE_URL`（`window.location.origin + window.location.pathname` で自動取得）
  - hashtags：`クオリアル`（1つ）
  - `window.open(..., '_blank', 'noopener,noreferrer')` で開く
  - 画像は X intent では自動添付できない（仕様上の制約）。ユーザーが「画像を保存」で取得した画像を手動で添付する想定
