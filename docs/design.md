# design.md（観察ベース逆生成）

> 既存コード `index.html`（元 `aoi-midori.html`）から抽出した UI 設計情報。
> スタイル決定はすべて既存コードに準拠。新規デザイン提案は含まない。

## デザインコンセプト
- 和紙風・ミニマル・モノクロベース＋朱（accent）
- 罫線と二重枠で「額装された測定器」を思わせる質感
- 微細なノイズテクスチャと淡いラジアルグラデで紙質感を演出

## カラーパレット（CSS 変数）
| 変数 | 値 | 用途 |
|---|---|---|
| `--bg` | `#f4efe6` | 背景（基調） |
| `--bg-deep` | `#ebe4d6` | 背景（深め）※未使用箇所あり |
| `--ink` | `#1a1a1a` | 主要テキスト |
| `--ink-soft` | `#4a4a4a` | 補助テキスト |
| `--ink-faint` | `#8a8378` | 弱テキスト・罫線色（淡） |
| `--line` | `#c8bfae` | 罫線・枠 |
| `--accent` | `#8b2929` | 朱（強調・タイトル） |
| `--paper` | `#faf7f0` | カード／パネル背景 |
| `--ref-green` | `hsl(142, 72%, 42%)` | 緑参照ブロック |
| `--ref-blue` | `hsl(220, 78%, 48%)` | 青参照ブロック |

### 色相補助
- 「緑」テキスト強調：`hsl(140, 50%, 28%)` / `hsl(140, 55%, 32%)`
- 「青」テキスト強調：`hsl(220, 65%, 32%)` / `hsl(220, 65%, 38%)`

## タイポグラフィ
| ファミリー | 用途 |
|---|---|
| Shippori Mincho B1（明朝） | ブランド名、見出し、ボタン、強調 |
| Noto Sans JP（ゴシック） | 本文 |
| Cormorant Garamond（欧文セリフ） | 番号付きリストの数字（イタリック） |

- ブランド名：明朝・太字・字間 0.5em（広く取る）
- 見出し：朱色・字間 0.5em
- ボタン：明朝・字間 0.3em〜0.35em（広め）

## レイアウト
### イントロ画面
- 中央寄せ、`max-width: 580px`
- ブランド → タグライン → 操作デモ（16:9）→「はじめる」ボタン

### テスト画面
- 全画面固定（`position: fixed; inset: 0;`）
- グリッド `0.85fr 2.1fr 0.85fr`（左基準・中央カード・右基準）
- モバイル時：`0.75fr 2.4fr 0.75fr`

### 結果画面
- 中央寄せ、`max-width: 720px`
- 構造：境界色スウォッチ＋色相情報 → グラデーションバー → 中間色サンプル → アクションボタン

## 共通装飾パターン
### 二重枠（紙の額装表現）
- 外側：影付きパネル（`box-shadow` 多重）
- 内側：`::before` で `inset: 5px〜8px` の `border: 1px solid var(--line)`
- 用途：操作デモ枠／結果まとめ／スウォッチ枠／グラデ枠／中間色サンプル枠／使い方モーダル

### 罫線装飾
- カード上下：`border-top` + `border-bottom` の細線（opacity 0.32）
- スウォッチ枠の四隅：`linear-gradient` で 8px の L 字マーク

### コーナーマーク（カード内カラー領域）
- 4 隅に 10×10 の L 字（`border-color: rgba(255,255,255,0.7)`）

## ボタンデザイン
- 黒背景＋紙白文字、字間広め
- ホバーで朱に変化＋上方向に持ち上がる
- 内側に `inset: 4px` の薄い枠（ホバー時 `inset: 8px` に広がる）

## アニメーション
- `fadeUp`：起動時のフェードイン＋下から上
- `pulse`：進捗ドットの現在位置パルス
- `modalFade` / `modalSlide`：モーダルの開き演出（cubic-bezier(0.34, 1.56, 0.64, 1)）
- `modalFadeOut` / `modalSlideOut`：モーダル閉じ演出
- カードのドラッグ：`transition: none` 中、リリース時に `cubic-bezier(0.34, 1.56, 0.64, 1)` でスナップ

## アイコン
- ヘルプ：明朝の `?` 文字
- リセット：SVG（円弧＋矢印、stroke 1.7）

## 背景レイヤー
- `body::before`：左上 18%/25% に朱の淡いラジアルグラデ、右下 82%/75% に深緑の淡いラジアルグラデ
- `body::after`：SVG fractalNoise の noise テクスチャ（不透明度 0.4）

## レスポンシブ規則
- 720px 以下：余白縮小、カード縮小、結果画面の境界色行を縦並びに
- 高さ 640px 以下：トップバー余白縮小、カード幅さらに縮小

## アクセシビリティ
- アイコンボタンに `aria-label` / `title`
- モーダルに `role="dialog"` / `aria-labelledby` / `aria-hidden`
- デモ要素に `aria-hidden="true"`
