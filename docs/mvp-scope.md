# MVP スコープ

## 目的
既存の単一HTMLツール（`aoi-midori.html` → `index.html`）を、清書のうえ GitHub Pages にデプロイして公開する。

## スコープ内
- 既存コードの観察ベース仕様化（`docs/spec.md` / `docs/design.md`）
- 共通規約の確定（`docs/conventions.md`）
- メタタグ・OGP・SEO・favicon の整備
- README の作成
- GitHub リポジトリ作成と GitHub Pages へのデプロイ
- 公開後の動作確認

## スコープ外（明示）
- 機能追加・仕様変更（バグ修正以外）
- デザインの再設計・配色変更
- ロジック・アルゴリズムの変更（二分探索のパラメータ等）
- 多言語対応
- アクセス解析・トラッキング
- バックエンド／API 連携

## 制約
- 既存実装を極力壊さず、最小差分で清書する
- 機能の振る舞いを変えない（メタ情報の付与・分割等は OK）
